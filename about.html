About

Grid Extreme Risk Toolkit (GERT)

GERT asks how close a demand tail sits to a boundary you can name. The software DOI is the concept record 10.5281/zenodo.23982226, version 1.2.0, published 2026-11-05. The dataset DOI is 10.5281/zenodo.22975251.

What this website will not do

  • It will not present estimated fallback load, such as a 45,000 MW / 65,000 MW pair, as ERCOT's current load.
  • It will not fill missing weather with placeholder temperatures or wind speeds.
  • It will not run scenario analysis while ercot-delta-quantile-v1.4 remains rejected. The Historical Lab is the calculation that stays available.
  • It will not treat organizer notes as adoption. The public wording is a few organizer-relayed sessions, hands-on runs, and 0 independent replications.

Grid Extreme Risk Toolkit (GERT) is decision-support research. It is not an autonomous grid controller, and this deployment does not show live ERCOT load.
